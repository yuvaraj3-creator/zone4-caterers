# Zone 4 Caterers — Website

A responsive, single-page catering website concept for Zone 4 Caterers.

## Preview
https://zone4-caterers.vercel.app

## Features
- Responsive mobile navigation
- Premium dark, cream and gold visual theme
- Catering services for weddings, family functions and corporate events
- Menu highlights and image gallery
- Event enquiry form with WhatsApp message generation (configure the real number before launch)
- Basic page metadata and semantic HTML

## Before client launch
1. Replace sample/stock images with client-approved photos.
2. Confirm the actual menu, service areas, address, and business contact details.
3. Set WHATSAPP_NUMBER in the inline script to the confirmed international-format number (digits only, including country code).
4. Verify all wording and claims with the client.

## Deploy
This is a static HTML website and can be hosted on Vercel. The repository's main branch is the production branch.
